# MetricGuard planning pack

Prepared for Aditya Beecha on 22 September 2026. Version 1.0. Status: proposed product and engineering specification, before implementation.

MetricGuard investigates why related KPI definitions produce different answers and records evidence when their meaning changes. The recommended first release compares a deliberately limited SQL subset on one immutable dataset. Broader BI integrations remain part of the product direction.

Start with `01_product_and_prd.md`, then `04_reconciliation_method.md`, then `05_architecture.md`. Read `09_delivery_plan.md` before opening a coding assistant. The PDF and Word document combine every chapter in reading order. This folder contains the editable specifications and diagrams, not an implemented application.

## Contents

1. Product refinement and PRD
2. User journeys and screen specifications
3. Metric contract and SQL support
4. Reconciliation and semantic drift method
5. Architecture and deployment
6. Data model and API contracts
7. Security and operational requirements
8. Demo data and evaluation plan
9. Backlog and delivery roadmap
10. Decisions risks and coding handoff
11. Sources and glossary

The `examples` folder contains a hand-verifiable eight-row CSV, three illustrative SQL definitions and proposed JSON contract examples. These are specification fixtures. The `diagrams` folder contains editable Mermaid sources and rendered architecture and workflow images.

All accuracy, performance, delivery and adoption targets are proposed acceptance criteria. No product benchmark, customer interview, deployment or user outcome is claimed. External capability statements are sourced in chapter 11; the architecture and product decisions are recommendations.

The project name is a working name. Domain availability and trademark clearance have not been checked.
